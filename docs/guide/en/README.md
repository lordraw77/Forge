# Forge user guide (English)

[Italiano](../it/README.md) · [Both languages and how the figures are made](../README.md)

Read the chapters in order the first time; later each chapter stands on its own. Every chapter starts with *who it is for* and ends with *troubleshooting*.

| # | Chapter | You will learn to… | Mainly for |
| --- | --- | --- | --- |
| 1 | [Getting started](01-getting-started.md) | sign in, find your way around, choose a project, set language, theme and two-factor authentication | everyone |
| 2 | [Projects Studio](02-projects-studio.md) | set up a project: models and aliases, limits, members, roles, groups, catalogs, API tokens | Project Admin |
| 3 | [Prompt Studio](03-prompt-studio.md) | write, version, test, compare and publish prompts | Builder |
| 4 | [Data and RAG Studio](04-data-and-rag.md) | load documents, schedule external sources, build RAG pipelines and get cited answers | Builder |
| 5 | [Tools Studio](05-tools.md) | define the tools agents can call: HTTP, SQL, MCP, Python | Builder |
| 6 | [Agentic AI Studio](06-agents.md) | create agents, chat with them, read runs, long-term memory | Builder, User |
| 7 | [Use cases](07-use-cases.md) | run use cases from the catalog, build your own, approvals, triggers | everyone |
| 8 | [Governance and Evaluation Studio](08-governance.md) | guardrails and quality evaluations | Project Admin, Builder |
| 9 | [Analytics](09-analytics.md) | usage, cost and activity dashboards | Project Admin |
| 10 | [Integrations, sync and transfer](10-integrations-and-sync.md) | MCP server, chat widget, OpenAI-compatible API, Git sync, export and import | Project Admin, developers |
| 11 | [Super Admin console](11-administration.md) | users, projects, platform models, authentication, settings, audit, vault, e-mail | Super Admin |
| 12 | [Installing and operating Forge](12-operations.md) | install, upgrade, back up and restore | administrators |

> **Status:** all twelve chapters are written in this language, with screenshots taken in English.

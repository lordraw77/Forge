# ADR-011 – API conventions

- Status: Accepted
- Date: 2026-10-16

## Decision

- **Surfaces**: management and product REST under `/api/v1/...`; OpenAI-compatible under `/v1/...` (`/v1/chat/completions`, `/v1/embeddings`, `/v1/models`) so standard SDKs work with `base_url=<public>/v1`.
- **Spec**: OpenAPI 3.1 generated by FastAPI, published at `/api/v1/openapi.json`; the Angular client is generated from it in CI.
- **Project context**: path-scoped for project resources: `/api/v1/projects/{project_id}/prompts/...`. API keys are bound to one project; the path must match.
- **Auth**: browser sessions use an HttpOnly, Secure, SameSite=Lax cookie with a short-lived JWT + rotating refresh token, plus CSRF double-submit token on unsafe methods. API clients use `Authorization: Bearer <api key>`.
- **Errors**: RFC 9457 `application/problem+json` with `type`, `title`, `status`, `detail`, `code`, `trace_id`.
- **Pagination**: cursor-based (`?cursor=&limit=`), `limit` max 200.
- **IDs**: UUIDv7 everywhere.
- **Versioned resources**: `GET /prompts/{id}` (latest), `GET /prompts/{id}/versions/{n}`, `POST /prompts/{id}/versions` (save = new version), `POST /prompts/{id}/publish`.
- **Async operations**: return `202` with a `job_id` / `run_id`; status via `GET`, events via SSE `GET .../events`, optional completion webhook (HMAC-signed).
- **Idempotency**: `Idempotency-Key` header on POSTs that start runs or ingestion.
- **Rate limit / quota** responses: `429` with `Retry-After` and `RateLimit-*` headers.
